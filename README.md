A make.fun bounty entry: one original line, at most 200 characters,
describing a hilariously useless superpower.

## The line

> I can freeze time, but only inside elevators — and only after someone else has already pressed my floor.

104 characters. All the grandeur of stopping time, none of the use:
you arrive exactly when you were going to anyway, just slightly more
smug about it.

## How it works

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
It validates the line first: 1–200 characters, not only whitespace.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
